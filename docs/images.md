## Image Standards for Rebuild

### Formats

| Use Case | Recommended Format |
|----------|--------------------|
| Logo / brand mark | SVG (vector, scalable) |
| Photos (people, office) | WebP with JPG fallback |
| Course thumbnails | WebP, 16:9 aspect ratio |
| Icons | SVG (inline or sprite) |
| OG/Social images | PNG or JPG, 1200×630px |
| Favicon | ICO (multi-size) + PNG |

### Naming Convention

```
/images/
├── brand/
│   ├── logo-dark.svg          (for light backgrounds)
│   ├── logo-light.svg         (for dark backgrounds)
│   └── favicon.ico
├── courses/
│   └── options-mastery-program.webp
├── team/
│   └── yeshwant-valecha.webp
└── og/
    ├── default-og.png
    ├── courses-og.png
    └── package-og.png
```

### Performance Requirements

- All images must have `alt` attributes (accessibility + SEO)
- Use `loading="lazy"` for below-the-fold images
- Course thumbnails: provide 2x resolution for retina displays
- OG images: exactly 1200×630px for optimal social sharing
- Maximum file size: Photos < 200KB, Icons < 10KB each
